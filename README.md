# Floatpad for Mac

Downloads for Floatpad's Mac app (macOS 12 Monterey or newer, Intel and Apple Silicon).

**[Download the latest version →](https://github.com/andyresonner/floatpad-releases/releases/latest)** (get the `.dmg`)

First install: drag Floatpad into Applications, then right-click it → **Open** (it isn't notarized by Apple).
After that, Floatpad updates itself: **Floatpad → Check for Updates…**
